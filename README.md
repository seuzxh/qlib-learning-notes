## 核心结论速览

口径统一：Alpha158 因子库；训练段 2020-01-02~2023-12-31；测试段 2025-01-01~2026-07-01；收益为相对沪深 300 的年化超额、含交易成本；组合策略为 TopkDropout（top50/drop5）。

- 18 个神经网络基线全面不敌树模型：最优神经网络为 TFT，年化超额 +12.08%；全场最优为 CatBoost（梯度提升决策树），+14.66%。
- 表格化因子数据上，梯度提升决策树仍是首选，与公开研究的普遍结论一致。
- HIST（图神经网络 + 概念板块先验）的秩信息系数 0.0576 为全场最高，说明小数据上注入结构先验有效。
